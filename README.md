# 📊 AI-Powered Sales & Inventory Analytics Dashboard

A smart interactive web application built with Python, Streamlit, and Scikit-Learn for sales analytics, inventory management, and predictive forecasting using Machine Learning.

## 🚀 Features
- Key Performance Indicators (KPIs): Real-time tracking of total revenue, top-selling products, and low-stock alerts.
- Interactive Data Explorer: Direct integration with Excel data sources.
- Visual Analytics: Dynamic bar charts showcasing product performance.
- AI Forecasting Engine: A Linear Regression model predicting sales volume dynamically based on pricing thresholds.

## 🛠️ Tech Stack
- Languages: Python
- Libraries: Pandas, NumPy, Matplotlib, Scikit-learn
- Web Framework: Streamlit
- Data Source: Microsoft Excel (openpyxl)
